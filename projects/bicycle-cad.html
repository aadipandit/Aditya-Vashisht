01 / PROJECT OVERVIEW

Project Overview

This project involved creating a complete bicycle assembly in SolidWorks. The bicycle was developed as a multi-part CAD assembly, with individual components modelled separately before being combined into the final assembly.

02 / ASSEMBLY STRUCTURE

FROM PARTS TO ASSEMBLY

The model was created using separate CAD parts that were brought together to form the complete bicycle assembly.
