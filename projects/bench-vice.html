01 / PROJECT OVERVIEW

Designed part by part.

This project explores the design of a bench vice as a complete CAD assembly. Each component is modelled from scratch as an individual part, then brought together to communicate how the parts make up the assembled tool.

02 / COMPONENT DESIGN

Every part has a role.

The vice is developed as a collection of separate components before being assembled. The labels below describe the key functional groups in a typical bench vice design.

01

Vice body & base

Supports the assembly and provides its mounting foundation.

02

Fixed jaw

Forms the stationary clamping face on the body.

03

Moving jaw

Travels toward the fixed jaw to hold a workpiece.

04

Lead screw

Transfers turning input into the jaw's linear movement.

05

Operating handle

Provides the manual input for opening and closing the vice.

06

Jaw faces & fixings

Contact and fastening details that complete the assembly.
